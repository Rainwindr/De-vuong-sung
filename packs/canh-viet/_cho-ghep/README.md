# Chờ ghép

Game không đọc thư mục này.

`cung-quy-giu-lai.json`: 3 lệ chưa ghép
- Lệ Bú Vú Nàng Mang Thai: cần code chọn đúng phi đang có thai vào cảnh.
- Lệ Cạo Sạch Lông Lồn: phạt nhét dưa chuột suốt đêm, gần với ép buộc.
- Lệ Rên To Khi Bị Địt: trùng với Lệ Rên To Đúng Kiểu, thêm phần phạt không có ám hiệu.
